# مستندات (فارسی)

راهنمای فارسی پروژه. برای جزئیات کامل انگلیسی به پوشهٔ [`docs/`](../) نگاه کنید.
اصطلاحات فنی ممکن است به انگلیسی بمانند.

## فهرست

- [شروع سریع](quickstart.md) — از ورود نخست تا اولین کاربر و تونل
- [نصب](installation.md) — نصب تکلاین، پیشنیازها و پروکسی معکوس
- [CLI](CLI.md) — مرجع خط فرمان
- [استفادهٔ مسئولانه](responsible-use.md) — استفادهٔ قانونی و مسئولیتها

## نکات مهم

- پنل بهصورت پیشفرض روی `127.0.0.1` گوش میدهد؛ برای دسترسی عمومی، یک
  پروکسی معکوس با TLS قرار دهید و `OVPN_TRUSTED_HOSTS` را تنظیم کنید.
- پس از نصب، فایل `/root/<slug>-install-info.txt` شامل گذرواژهٔ مدیر است؛
  پس از نخستین ورود، گذرواژه را تغییر دهید و آن فایل را حذف کنید.
- هیچ تلمتری و کلید لایسنسی در پروژه وجود ندارد؛ بررسی بهروزرسانی اختیاری
  و پیشفرض خاموش است.
